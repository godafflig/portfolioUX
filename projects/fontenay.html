Description

Prototype de gestion de salle et de service pour un restaurant : réservation en ligne côté client, plan de salle en temps réel et prise de commande à table côté serveurs, écran cuisine synchronisé.

Stack technique

  • Symfony 7, PHP 8
  • React, TypeScript, Vite
  • PWA
  • PostgreSQL
  • Docker Compose
  • GitHub Actions (CI)
