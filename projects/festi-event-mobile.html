Festi-Event Mobile

FM

Description

Application mobile connectée au backend Symfony de Festi-Event via API REST : connexion, consultation des billets avec QR code, suivi des candidatures artiste.

Authentification JWT avec token persisté localement, AuthGate qui redirige automatiquement selon l'état de session, déconnexion forcée sur 401. QR codes reçus en data URL base64 (SVG/PNG) et décodés côté client.

Stack technique

  • Flutter / Dart 3.11
  • http
  • shared_preferences
  • flutter_svg
  • Builds Android, iOS et web

Mon rôle

Conception et développement de l'application : séparation nette models / services / screens, configuration d'environnement centralisée, pull-to-refresh, et états visuels explicites (billet valide/utilisé, candidature en attente/confirmée/refusée).
