Festi-Event

FE

Description

Plateforme de gestion de festivals musicaux, avec un espace web pour les organisateurs et les artistes et une application mobile pour les festivaliers (billets, QR code, suivi des candidatures).

Stack technique

  • Flutter
  • Build Android
  • Stripe
  • AWS
  • Symfony
  • PostgreSQL
  • Docker

Mon rôle

Conception et développement de l'ensemble de l'application : architecture des trois parcours (organisateur, artiste, festivalier), logique métier isolée en services, migrations versionnées, routes et rôles documentés.

Conception et développement de l'application mobile Flutter connectée à cette même API : séparation nette models / services / screens, configuration d'environnement centralisée, pull-to-refresh, et états visuels explicites (billet valide/utilisé, candidature en attente/confirmée/refusée).

Mise en place de l'infrastructure Docker : Docker Compose multi-services, Dockerfile multi-stage dev/test/prod, et un entrypoint qui provisionne tout au démarrage (base, migrations, clés JWT, assets) — un docker compose up et le projet tourne.
