Festi-Event

FE

Description

Plateforme de gestion de festivals musicaux réunissant trois parcours : l'organisateur crée son festival, ses scènes et ses créneaux ; l'artiste dépose un profil avec démos et candidate ; le festivalier achète ses billets par Stripe.

Hiérarchie de rôles à 4 niveaux (utilisateur / artiste / organisateur / admin), stockage S3 avec URLs présignées pour les fichiers privés, e-mails transactionnels automatiques à chaque décision sur une candidature, et une API REST authentifiée en JWT doublant l'interface web.

Application mobile compagnon disponible : Festi-Event Mobile, le client Flutter connecté à cette même API.

Stack technique

  • Symfony 8, FrankenPHP
  • PostgreSQL 16, Doctrine
  • Stripe (paiement)
  • AWS S3 / MinIO (stockage)
  • Gotenberg
  • Leaflet
  • Stimulus (Symfony UX), Bootstrap 5
  • LexikJWT (API REST authentifiée en JWT)
  • Docker

Mon rôle

Conception et développement de l'ensemble de l'application : architecture des trois parcours (organisateur, artiste, festivalier), logique métier isolée en services, migrations versionnées, routes et rôles documentés.

Mise en place de l'infrastructure Docker : Docker Compose multi-services, Dockerfile multi-stage dev/test/prod, et un entrypoint qui provisionne tout au démarrage (base, migrations, clés JWT, assets) — un docker compose up et le projet tourne.
